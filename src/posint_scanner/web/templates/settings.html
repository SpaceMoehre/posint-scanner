Global proxy



Leave the proxy empty to connect directly. When set, every connection a scan makes goes through it, or is not made: HTTP(S) requests, git/trivy/checkov and other tools (via ALL_PROXY), nuclei/subfinder/wpscan (their own proxy flag), the port scan (TCP tunnelled) and DNS (sent over TCP through the proxy to the DNS server above; hostnames in HTTP requests resolve at the proxy). Tools that can't be tunnelled are skipped: ping (ICMP), Nikto, takeover, theHarvester. A scan refuses to start if the proxy is unreachable. socks5:// is treated as socks5h:// (remote DNS). Credentials go in the URL (socks5h://user:pass@host:port) and are stored in plain text in the DB.
